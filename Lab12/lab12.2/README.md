##  Project Overview

This project demonstrates responsive design techniques in React Native using Flexbox, Safe Area handling and adaptive layouts.

The app automatically adapts to different screen sizes such as:
- mobile portrait
- mobile landscape
- tablet view

---

## Components

### 1. GridLayout
- Responsive grid system
- Uses useWindowDimensions
- Supports multiple columns
- Handles spacing between elements

### 2. ResponsiveHeader
- Safe area support
- Left and right action buttons
- Adaptive font size for tablet
- Platform-specific adjustments

### 3. AdaptiveLayout
- Works for phone and tablet
- Supports landscape mode
- Uses ScrollView
- Splits layout into sections

##  Responsive Features
